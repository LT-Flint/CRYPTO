# CRYPTO
Функция текстирования шифрования паролей через обфускацию пароля через XOR и Base64. В исходном коде вместо открытого пароля будет храниться закодированная строка, а при запуске функция Cry_pass() восстановит пароль и присвоит его обратно переменной SSH_PASSWORD.
Это не криптографическая защита, а скрытие пароля от беглого просмотра кода. Человек, имеющий исходник и ключ, сможет восстановить пароль.
base64.b64decode() преобразует её в байты.
b ^ KEY выполняет операцию XOR для каждого байта.
.decode("utf-8") восстанавливает обычную строку.
